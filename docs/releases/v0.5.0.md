# v0.5.0 — Deployable Private Beta

- 状态：发布文档已完成；不代表已创建 Render 资源或公开 URL
- 日期：2026-07-31

## 范围

- production 只允许 PostgreSQL 与 S3-compatible 私有存储；local/test 保留 SQLite 与本地存储。
- SQLAlchemy 2 连接/事务适配和 Alembic 有序 migration，不进行 ORM 业务重写。
- `open`、`invite_only`、`disabled` 注册模式；邀请码哈希、次数、到期与管理员 CLI。
- 导出默认 7 天保留、到期下载拒绝、幂等清理任务和短期 S3 presigned URL。
- Application、Resume、Export 和 Account 删除，并同步清理导出对象。
- live/ready 探针、production 配置 fail-fast、非 root Docker 和 GitHub Actions。
- Beta 标识、去标识化提示、保留说明、邀请码字段和账号数据删除入口。
- Production 关闭 AI Labs，保留 local/test 显式开启能力；DeepSeek 是唯一默认 Provider，不隐式 fallback 到 Claude。
- Career 分析 2/日、建议生成 2/日、单条重生成 8/日、Resume Export 5/日，按用户和 UTC 日期持久化。
- 简历和 JD 各 20,000 字符上限，超长在模型调用前拒绝且不消耗额度。
- Production Session 使用 `HttpOnly; Secure; SameSite=Lax` Cookie，前端不保存 Token。
- `render.yaml` 定义 Singapore Starter Docker Web Service、Render PostgreSQL、Alembic pre-deploy migration、checks-pass auto deploy 和 R2 Secret 注入。

## API 变化

- 新增 `GET /health/live`、`GET /health/ready`、`GET /config/public`。
- 新增 `GET /usage/daily`，只返回当日计数、剩余数和 UTC 重置时间。
- `POST /auth/register` 支持 `invite_code`。
- 新增 `DELETE /auth/account` 和 `DELETE /career/resumes/{resume_id}`。
- 导出详情可返回计算状态 `expired`；到期下载返回 `410 export_expired`。
- S3 下载返回短期重定向，本地存储继续由鉴权 API 直接返回文件。

## 数据库与存储

- 新增 `invite_codes`，只保存 HMAC-SHA256 code hash、次数、有效期和创建管理员。
- 新增 `daily_usage`，复合主键为 `(user_id, usage_date, usage_type)`，使用事务内条件更新防止并发超额。
- `resume_exports.expires_at` 进入实际生命周期判断。
- PostgreSQL schema 由 `20260730_01` 基线、`20260731_02` Private Beta 和 `20260731_03` Launch Guardrails revision 管理。
- object key 采用 `users/{user_id}/resume-exports/{random}`；对外文件名不参与物理路径。

## 安全与隐私

- production 缺少 PostgreSQL、S3、DeepSeek Key、CORS、SESSION_SECRET、Secure Cookie 或邀请模式时拒绝启动，错误只列变量名。
- 简历/PDF/CSV 文档预览不写活动日志；其他有限预览经过邮箱、电话和凭据脱敏。
- 邀请明文仅由 CLI 显示一次；密码、Token、API Key、签名 URL 和完整用户材料不进入日志。
- 删除对象优先于数据库级联；对象删除失败时保留数据库记录并返回可重试错误。

## 已知限制

- Render Blueprint 已通过本地解析与合约测试，但尚未创建真实云资源、域名、HTTPS、备份、告警或公开 URL。
- 本机没有 Docker/PostgreSQL，真实 PostgreSQL 测试需由 CI 或受控部署环境执行。
- S3 测试使用 fake client，不代表已完成特定云厂商验收。
- 清理任务需要外部 scheduler；没有自动备份恢复演练。
- 已有持久化用户日额度，但没有通用 IP 级流量清洗或恶意文件扫描；Provider 数据处理条款仍需在邀请真实用户前复核。
- 没有 OCR、公开分享、Cover Letter 或面试模拟。
