# v0.4.0 Draft — Resume Export & Delivery

状态：功能分支已实现并完成本地验收，尚未合并 `main`、未创建 `v0.4.0` tag。

## 功能范围

- 从归属当前用户的任意 ResumeVersion 打开导出工作区。
- 用确定性规则生成可追溯的 `StructuredResume`，保留源版本原文和哈希。
- 在浏览器中校对姓名、联系方式、摘要、经历、项目、教育、技能、证书、奖项和补充信息。编辑只影响当次导出，不覆盖 ResumeVersion。
- 选择 `professional` 或 `minimal_ats`、A4 或 Letter、中文/英文/双语章节标题。
- 从同一确认 Schema 生成 DOCX 和 PDF，查看历史、重复下载或删除。
- 安全下载名自动包含姓名、公司、岗位和版本。

## 模板

### professional

单栏商务风格，深蓝标题层级、细分隔线、对齐的日期/地点和稳定项目符号。适合商业、咨询、金融和数据分析岗位，不使用照片、进度条或复杂图形。

### minimal_ats

单栏、全黑、标准字体和顺序文本。不使用表格、文本框、多栏、图标或背景图形，优先保持 ATS 读取顺序。

## Resume Schema

`StructuredResume` 包含 `original_text`、`basics`、`education`、`experience`、`projects`、`skills`、`certifications`、`awards` 和 `additional_information`。Experience/Project/Education 条目支持 organization、title、location、start/end date 和 bullet points。

结构化不调用 LLM，不补全缺失事实。无标准章节时返回 `needs_review` 和明确提示，用户必须在导出前校对。

## API

- `GET /career/resume-versions/{version_id}/preview`
- `POST /career/resume-versions/{version_id}/exports`
- `GET /career/resume-exports`
- `GET /career/resume-exports/{export_id}`
- `GET /career/resume-exports/{export_id}/download`
- `DELETE /career/resume-exports/{export_id}`

全部接口需要 Session 并校验当前用户。下载响应使用准确 `Content-Type` 和安全 `Content-Disposition`，API 不暴露本地绝对路径。

## 数据库变化

`database/migrations/0003_resume_exports.sql` 新增 `resume_exports`，记录用户/Resume/Version 所有权、模板、格式、纸张、语言、状态、安全下载名、随机对象名、确认后 Schema、三类哈希、错误码和生命周期时间。

状态为 `pending -> generating -> ready|failed`，以及 `ready|failed -> deleted`。临时文件成功原子移动后才进入 `ready`；失败不留伪文件。

## 文档生成

- DOCX：`python-docx`，显式纸张、页边距、字体、标题层级、项目符号和分页保持。
- PDF：ReportLab 直接从同一 Schema 排版，不依赖 LibreOffice 转换。英文使用 PDF 标准字体；中文必须找到可注册的 Unicode CJK 字体，否则返回 `pdf_font_unavailable`。
- 两种格式共享章节顺序与确认数据，不使用 LLM 重写。

## 安全与隐私

- 下载名与内部随机对象名分离。
- 所有文件路径约束在 `RESUME_EXPORT_DIR`，并检查目录穿越。
- 临时文件、数据库、`.env`、默认导出目录、虚拟环境和缓存不进入 Git。
- 导出不包含 API Key、Prompt、风险分析或内部路径，也不把简历正文写入 activity log preview。

## 测试与验收

- 86 项后端/静态自动化测试全部通过，其中 28 项是 Resume Export 专项。
- 5 项可选 Playwright 浏览器契约已提供；本轮未在仓库安装 Chromium，而是使用现有浏览器完成了真实 HTTP 验收。
- 真实浏览器验收通过：静态资源 200、登录、ResumeVersion 加载、导出预览、DOCX/PDF 生成、下载提示、桌面/390 px 小屏无页面横向溢出、控制台无 error/warn。

## 已知限制

- 确定性解析依赖常见章节标题；非标准自由排版需要用户手工校对。
- 导出保留结构与段落顺序，不恢复原始文件字体、双栏、图片或像素级版式。
- 本地同步存储只适合单实例原型；尚无对象存储、异步队列、自动过期清理或恶意文件扫描。
- 尚无 OCR、Cover Letter、面试模拟、公开分享链接或部署。
