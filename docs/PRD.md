## 一、产品背景与目标

### 1.1 背景

日常工作中，简历修改、文案撰写、文件阅读、数据预览等任务频繁出现，但直接使用公开 AI 聊天工具存在两个问题：一是每次重新描述需求，效率低；二是平台无法追踪团队用量和使用效果。

Nova AI 智能工作台的出发点是：**把高频的 AI 任务收束进一个统一入口，让每个人"开箱即用"，同时让管理员看到团队实际在用什么。**

### 1.2 目标

- 用户无需了解提示词工程，直接输入原始内容即可获得 AI 处理结果。
- 所有操作有登录身份绑定，行为可追溯。
- 管理员能实时查看各账号的使用频率和成败情况。

### 1.3 不在本版本范围内

- 忘记密码 / 邮件验证
- 历史记录查看（用户侧）
- 流式输出（逐字显示）
- 多语言界面
- 文件下载与导出

## 三、用户场景

**场景 A — 简历优化**  
张三需要投递实习岗位，把自己写的项目经历粘贴进来，AI 自动强化量化表达和行动动词，输出一版更专业的中文简历片段。

**场景 B — 文案生成**  
李四要给一款产品写朋友圈推广文，描述产品和语气要求后，直接拿到成稿，微调后发布。

**场景 C — 翻译润色**  
王五写了一段英文邮件草稿，贴入翻译助手，AI 自动识别为英文并输出自然中文，或反向翻译。

**场景 D — PDF 摘要**  
管理员收到一份 20 页的调研报告，上传后 AI 提取核心结论和关键数据，几分钟内掌握要点。

**场景 E — CSV 分析**  
数据同学拿到一张陌生的 CSV 表格，上传后 AI 说明字段含义、数据量级和可能的分析方向，帮助快速判断数据价值。

## 四、功能需求

### 4.1 账户体系

#### 注册

| 字段 | 规则 |
|------|------|
| 用户名 | 3–32 位，仅限小写字母、数字、下划线 |
| 密码 | 8–128 位，必须同时包含字母和数字 |
| 姓名 | 1–30 个字符，展示用 |

- 注册成功后自动登录，返回 session token。
- 不允许用户自行注册为管理员，角色固定为普通用户。
- 用户名唯一，重复注册返回 409 错误。

#### 登录 / 退出

- 登录成功返回 token，有效期 12 小时，存储在浏览器 `localStorage`。
- 每次请求通过 `X-Session-Token` 请求头鉴权。
- 退出时服务端删除 session，本地清除 token。
- 登录态在 Header 区域实时展示用户姓名和角色。

#### 密码安全

- 密码使用 PBKDF2-SHA256 加盐哈希，迭代 20 万次，数据库中不存明文。
- 登录比对使用 `hmac.compare_digest` 防止时序攻击。

---

### 4.2 AI 工具模块

所有工具需登录后使用，未登录点击按钮提示"请先登录"。

#### 4.2.1 简历优化

- **输入**：简历片段或项目经历文本（文本框，无长度硬限制，建议包含岗位、职责、成果）
- **处理**：AI 强化量化表达、行动动词、岗位匹配度
- **输出**：优化后的中文简历文本，纯文本展示
- **模型**：DeepSeek（默认）或 Anthropic Claude（可切换）

#### 4.2.2 文案生成

- **输入**：场景描述（产品、受众、渠道、语气）
- **处理**：AI 生成适合营销/社媒/活动场景的短文案
- **输出**：直接给出成稿，纯文本展示

#### 4.2.3 翻译助手

- **输入**：任意中文或英文文本
- **处理**：自动识别源语言；中文→英文，其他语言→中文
- **输出**：译文，只输出结果，不附说明

#### 4.2.4 PDF 摘要

- **输入**：PDF 文件上传（仅限 `.pdf`，最大 20 MB）
- **处理**：提取前 8 页文字（最多 12000 字符），AI 生成核心结论、关键数据、行动建议
- **输出**：带小标题的结构化摘要
- **错误处理**：文件为空、超限、无可提取文字时给出明确提示

#### 4.2.5 CSV 预览

- **输入**：CSV 文件上传（仅限 `.csv`，最大 20 MB）
- **处理**：自动识别编码（UTF-8 / GBK），取前 30 行、每行前 20 列作为样本
- **输出**：AI 说明字段含义、数据规模、质量问题、明显趋势和后续分析建议

---

### 4.3 管理员后台

仅管理员账号可见，登录后导航栏出现"后台数据"入口。

**账号汇总**（聚合表格）

| 展示列 | 说明 |
|--------|------|
| 账号 / 姓名 / 角色 | 基础信息 |
| 调用次数 | 总请求数 |
| 成功 / 失败次数 | 分别统计 |
| 最近活动时间 | 最后一次请求时间 |

**平台汇总指标**：账号总数、总调用次数、失败次数，卡片形式展示。

**最近请求明细**（最多 100 条）

| 展示列 | 说明 |
|--------|------|
| 时间 | UTC 转本地时间显示 |
| 用户 | 姓名 + 账号 |
| 功能 | 工具名称 |
| 状态 | 成功 / 失败 |
| 耗时 | 毫秒 |
| 内容摘要 | 输入前 500 字或错误信息 |

## 五、非功能需求

### 5.1 安全

- 所有工具接口强制鉴权，session 过期或不存在均返回 401。
- 管理接口在鉴权之上额外校验角色，非管理员返回 403。
- 上传文件限制大小和类型，防止恶意文件处理。

### 5.2 响应式与兼容性

- 页面在桌面（>980px）、平板（620–980px）、手机（<620px）三个断点均可正常使用。
- 移动端导航栏转为横向滚动，输入区域自适应宽度。

### 5.3 错误反馈

- AI 服务未配置密钥 → 返回"未配置 API Key"提示。
- AI 服务调用失败 → 返回"服务调用失败"并记录错误日志。
- 文件类型 / 大小不合规 → 前端拦截并展示原因，不发起请求。

### 5.4 可观测性

- 每次工具调用写入 `activity_logs`，记录功能名、状态、耗时、输入摘要、输出摘要和错误信息。
- 管理员无需查数据库，直接在后台界面查看。

## 六、数据模型

```
users
  id, username, password_hash, salt, display_name, role, is_active, created_at

sessions
  token (PK), user_id (FK), created_at, expires_at

activity_logs
  id, user_id (FK), feature, input_preview, output_preview,
  status, error, duration_ms, metadata (JSON), created_at
```

外键均设 `ON DELETE CASCADE`，删除用户时自动清除其 session 和日志。

## 七、接口

| 方法 | 路由 | 鉴权 | 说明 |
|------|------|------|------|
| POST | `/auth/login` | 无 | 登录，返回 token |
| POST | `/auth/register` | 无 | 注册并自动登录 |
| POST | `/auth/logout` | token | 退出，销毁 session |
| GET | `/auth/me` | token | 获取当前用户信息 |
| POST | `/resume` | token | 简历优化 |
| POST | `/copywrite` | token | 文案生成 |
| POST | `/translate` | token | 翻译润色 |
| POST | `/pdf-summary` | token | PDF 摘要（multipart） |
| POST | `/csv-preview` | token | CSV 分析（multipart） |
| GET | `/admin/users` | admin | 账号汇总统计 |
| GET | `/admin/logs` | admin | 最近请求明细 |

## 八、设计决策说明

| 决策 | 选择 | 原因 |
|------|------|------|
| 数据库 | SQLite | 轻量、零配置，适合小团队内部工具 |
| 前端框架 | 原生 HTML/JS | 无构建依赖，部署简单，功能复杂度不需要框架 |
| AI 提供商 | DeepSeek 默认，Anthropic 备选 | DeepSeek 性价比高；保留 Claude 作为质量兜底 |
| 鉴权方式 | 自建 session token（Header） | 无需引入 OAuth 或 JWT 库，代码简单透明，适合内部系统 |
| 密码存储 | PBKDF2-SHA256 + 随机盐 | Python 标准库支持，安全性足够，无需第三方依赖 |

## 九、已知局限与后续方向

| 问题 | 说明 | 可能的改进 |
|------|------|-----------|
| 无流式输出 | 等待 AI 返回期间无进度反馈 | 改用 Server-Sent Events 逐字输出 |
| 无历史记录 | 用户看不到自己的历史请求结果 | 增加"我的记录"页面 |
| 无密码找回 | 忘记密码只能联系管理员重置 | 接入邮件服务 |
| 并发未限流 | 高并发时 AI 接口可能超时 | 加队列或速率限制 |
| PDF 仅读前 8 页 | 长文档覆盖不全 | 分块摘要后再汇总 |
